# Data Science Projects

A collection of data science projects covering machine learning, exploratory data analysis, and data visualisation implemented in Python.

## Overview

These projects explore real-world datasets using a range of data science techniques — from statistical analysis and feature engineering to model training and evaluation. Each project is self-contained with its own notebook.

## Tech Stack

- Python
- Pandas · NumPy · Matplotlib · Seaborn
- Scikit-learn
- Jupyter Notebook

## Getting Started

1. Clone the repository
2. Install dependencies or set up a Python environment with the libraries above
3. Open any notebook in Jupyter and run cells sequentially
